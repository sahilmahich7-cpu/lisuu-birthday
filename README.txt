LISUU BIRTHDAY WEBSITE

GitHub Pages publishing:
1. Sign in to GitHub.
2. Tap the + button, choose New repository.
3. Name it lisuu-birthday and set it to Public.
4. Create repository.
5. Choose Add file > Upload files.
6. Upload index.html and the assets folder (containing lisuu-collage.png).
7. Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select Branch: main and Folder: /(root), then Save.
11. Wait a minute or two. Your website link will look like:
   https://YOUR-USERNAME.github.io/lisuu-birthday/

Keep index.html and the assets folder together in the repository root.
